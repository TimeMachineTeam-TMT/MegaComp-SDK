MegaComp SDK: How to use

Welcome to MegaComp SDK's Instruction Guide!
This guide will teach you how to use this SDK.

WHAT DOES IT DO?:
MegaComp SDK gets a standard Mega Drive/Genesis (No SegaCD, no 32x) ROM and 
transforms it into x86_64 Assembly you can build with MASM. Yes, playing NATIVELY!

REQUIREMENTS FOR USING:
- A regular MegaDrive/Genesis ROM (No SegaCD, no 32x)
- Python

HOW TO USE:
1-Start the "MegaComp.py" script
2-Insert the ROM's path
3-Wait for the <ROMname>_x64.asm file to appear at the OUTPUT folder
4-Build it using MASM (ml64.exe) and your regular linker
